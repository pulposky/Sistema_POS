notas del sistema pos - para acordarme como funciona

--------------------------------

entrar

abro la app, sale la pantalla de bienvenida, le doy click a
"SenaEmpresa" y ahí me manda al login.

(foto de esa pantalla)

en el login pongo usuario y contraseña, doy enter o click en
"Ingresar". si me equivoco en algo me tira error, revisar mayúsculas
si pasa eso.

(foto del login)

con escape me devuelvo si me arrepiento.

--------------------------------

el menú

ya logueado salen los botones:
facturación, compras, remisión, inventario, nuevo usuario,
consultar facturas, cerrar sesión

(foto del menú)

si estoy logueado como aprendiz no puedo crear usuarios. si es
consultas solo puedo ver facturas y ya, todo lo demás sale apagado.
admin ve todo.

me puedo mover con flechas y enter tmb, no toca usar mouse siempre.

--------------------------------

vender (facturación)

1. busco cliente -> F1
2. busco producto y pongo cantidad -> F3
3. repito 2 con cada producto
4. reviso el total
5. facturar -> F2
6. elijo pago: transferencia / efectivo / mixto / crédito
7. queda guardada y sale el pdf

(foto pantalla completa de facturación)
(foto ventana buscar producto)
(foto ventana de métodos de pago)

si me equivoco: click en la cantidad para cambiarla, o la X de la
fila para quitar el producto.

ojo con el F4: si lo aprieto una vez limpia todo para empezar otra
venta. si lo aprieto dos veces sin haber facturado, abre otra
ventana aparte (para no perder la venta que ya llevaba)

F6 y F7 = ver facturas anteriores sin salir de la pantalla (ahí no
se puede editar, solo mirar)

teclas de esta pantalla:
F1 cliente
F2 facturar
F3 producto
F4 nueva factura / otra ventana
F5 borrar factura actual
F6 siguiente factura
F7 factura anterior
F8 crear cliente o producto rapido
esc volver al menu

--------------------------------

compras

es como facturación pero al revés, aquí compro yo, busco proveedor
en vez de cliente.

1. buscar proveedor F1
2. agregar productos con cantidad F3
3. revisar total
4. F2 para guardar

(foto pantalla de compras)

al guardar la compra el stock sube solo, no toca hacer nada más.

mismas teclas que facturación, cambia que es proveedor no cliente.

--------------------------------

remisión

esto NO es venta. es cuando sale un producto pero no se vendió.
motivos:
- se dañó
- consumo interno / degustación
- donación
- se transformó en otro producto

(foto pantalla de remisión)

busco cliente/destino si aplica (F1), elijo el motivo de la lista,
agrego productos (F3), F2 para generar.

no hay total en plata porque no es venta.

mismas teclas F1-F8 y esc.

--------------------------------

inventario

solo para mirar, no se edita nada acá.
muestra lo que tiene poco stock o ya está en negativo.

(foto de inventario)

rojo = negativo
naranja = bajo

F5 para recargar la lista si acabo de vender o comprar algo.

--------------------------------

consultar facturas

para buscar algo que ya hice antes (venta, compra o remisión)

filtros: numero, cliente/proveedor, usuario, tipo, fechas, producto

(foto de consultar facturas)

F2 = exportar a excel lo que esté viendo en la tabla
F5 = recargar
esc = volver

--------------------------------

nuevo usuario

esto solo lo veo si soy admin.

pide: nombre, usuario, rol (admin/aprendiz/consultas), contraseña

si el rol es aprendiz o consultas la contraseña la pone el sistema
sola. si es admin la escribo yo.

(foto de crear usuario)

guardar y listo.

--------------------------------

cosas que se repiten en todas las pantallas

buscar producto: nombre, enter, lo elijo, pongo cantidad
buscar cliente/proveedor: nombre, enter, lo elijo

F8: funciona en venta/compra/remisión para crear cliente, proveedor
o producto sin salirme de lo que estaba haciendo

confirmaciones: cuando pregunta si estoy seguro de borrar algo,
enter = confirmar, esc = cancelar

(foto de la ventana de confirmar)

--------------------------------

cosas que se me suelen olvidar

- si me equivoco con un producto: X para quitar, click en cantidad
  para cambiar
- para atender dos ventas a la vez: F4 dos veces
- para ver algo que ya hice: F6/F7 ahí mismo, o consultar facturas
- si no veo "nuevo usuario" es porque no soy admin
- si no me deja entrar: revisar mayúsculas y espacios de más

--------------------------------

todas las teclas juntas

esc - volver / cerrar sesión
enter - confirmar / buscar
F1 - cliente o proveedor
F2 - facturar (o exportar excel en consultar facturas)
F3 - producto
F4 - nuevo documento
F5 - borrar actual / recargar
F6 - siguiente documento
F7 - documento anterior
F8 - crear cliente/proveedor/producto rápido
flechas - moverse en el menú
