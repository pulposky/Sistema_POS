# 🛒 POS System — Gestión Comercial con Flet & MySQL
 
Sistema de punto de venta (POS) desarrollado en **Python con Flet**, diseñado para gestionar ventas, remisiones, clientes y productos de forma rápida y organizada.
 
---
 
## ✨ Características
 
- 📦 **Gestión de inventario** en tiempo real
- 🛍️ **Registro de ventas** y remisiones
- 👥 **Administración de clientes**
- 🧾 **Generación de facturas en PDF**
- 🗄️ **Base de datos MySQL** para almacenamiento persistente
- 🖥️ Interfaz de escritorio construida con **Flet**
---
 
## 🗂️ Estructura del Proyecto
 
```
.venv/                  # Entorno virtual (no incluido en git)
App/
├── assets/             # Recursos estáticos (imágenes, iconos)
├── controllers/        # Lógica de negocio
├── database/           # Conexión y configuración de MySQL
├── models/             # Modelos de datos
├── routers/            # Navegación entre vistas
├── utils/              # Funciones auxiliares
├── views/              # Vistas de la interfaz (Flet)
│   ├── inicio.py
│   ├── login.py
│   ├── menu.py
│   ├── comprar.py
│   ├── vender.py
│   └── remision.py
└── main.py             # Punto de entrada
.gitignore
requirements.txt
```

## 🛠️ Tecnologías
 
| Tecnología | Uso |

| Python     | Lenguaje principal |

| MySQL      | Base de datos |
| ReportLab / FPDF | Generación de PDFs |
